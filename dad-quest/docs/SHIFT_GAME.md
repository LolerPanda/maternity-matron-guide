# 把休息排进生活 · 屋里的这一班

[进入游戏](../shifts.html)

这一章改为直接操控爸爸的家庭场景。方向键或 WASD 移动，E 或空格与身旁物件互动，Esc 收起记录或暂停。点击地面和“走向”按钮会绕开家具；到达后仍需要亲自互动。手机可用方向按钮与互动按钮。

## 连续行动

1. 走到交接桌，听清当前需要、未办事务和接班条件。
2. 到手机确认双方有空的成人联络时间。接过玄关用品，带到右侧用品架；携物速度较慢，家具会阻挡走动。
3. 队友途中晚到。到场后当面说明三项责任，等她实际走到陪伴区。
4. 关闭电视、调柔灯光、静音非紧急消息，同时保留求助渠道；在玄关落实休息约定。
5. 走到休息床开始休息。亲友的非紧急来电出现时，在床旁请队友协调回复，她继续留在陪伴区。可以随时起身，已有休息进度保留。
6. 回交接桌听清休息期间的新情况，再确认下一班责任。

剧情用时与来电均为虚构。只练习成人家庭分工，不给新生儿规定喂养与睡眠时间，不模拟诊疗，不保证健康结果。操作慢、暂停和起身不会造成健康惩罚。

## 续存与兼容

新场景使用 `dad-shift-room-v1`。旧 `dad-recovery-v2-shifts` 进度和系列足迹保留，不转换为新动作。旧默认入口 `recovery.html?chapter=shifts` 转到新场景；`recovery.html?chapter=shifts&legacy=1` 保留上一版分工原型。

暂停、离开页面与刷新会清除按键、行走路径、未完成摆放和正在进行的休息，已完成事务与休息进度保留。音乐默认开启，首次进入时启动；暂停时停止，手动静音会在本次游玩中保留。
