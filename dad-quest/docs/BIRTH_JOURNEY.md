# 迎接你：分娩陪伴续篇

[公开入口](https://lolerpanda.github.io/maternity-matron-guide/dad-quest/birth.html)

本篇承接 `labor.html` 的入院、准备与需求沟通，连接到住院与出院交接。原陪产篇不再直接跳转到宝宝已出生，而在分娩前交接后邀请玩家继续本篇。也可以从成长地图独立进入。

## 一间房，十二个连续时刻

1. 拉上隐私帘，保留她需要的空间。
2. 在医护允许下，按本人反馈调整陪伴灯。
3. 走到床头，握手；她提出想休息时松开。
4. 拖开挡住通道的陪伴椅；触屏和键盘用户也可使用方向按钮。
5. 走到她看得见的床头位置。
6. 听她与医护沟通当下安排。
7. 陪着经历温和、非露骨的出生叙事。玩家可以握手、在她同意后头贴头，或不触碰；出生不由操作成绩触发。
8. 医护完成当下评估、妈妈愿意后，由医护协助开始肌肤接触。
9. 调整示意毯，保持小脸露出，继续由医护观察。
10. 在工作人员引导下共同核对虚构的母婴腕带标识。
11. 妈妈提出新的不适时呼叫医护，并转达希望获得喂养支持的需要。
12. 收好出生与后续安排记录，回到妈妈身边，继续住院交接。

舞台正文、操作与提示放在画布外，不遮挡人物。无倒计时失败、无健康分数或受伤惩罚。动作、光照、座椅位置、人员站位与新生儿出现均有场景反馈。按方向键/WASD或点击地面移动；椅子可拖拽、方向键或按钮移动；整理椅子期间爸爸留在椅旁，放手后不继续执行旧走路路线；握手可按住按钮或在画布聚焦时按住空格。滑块支持键盘方向键。可随时暂停，切后台自动暂停。

## 头贴头与出生纪念

出生叙事与初次接触的两个阶段（内部 `stage 6/7`）新增可选互动。妈妈在剧情中同意后，爸爸走到床头，可以选择轻轻头贴头；爸爸会倾身靠近，额头相贴。结束后回到站姿，不改变人物脚下的位置。头贴头、握手与使用手机不会同时进行。

打开游戏手机，将取景滑块调整到 **45–65** 范围，待剧情中的宝宝出生后点击截屏，即可生成 **PNG 纪念图** 并下载。截取范围仅为本页游戏画面，不调用操作系统截屏功能或设备相机。头贴头与截图都不影响主线推进，也没有完成期限；取景与截图可以无限重试。

本局剧情中宝宝出生的瞬间，游戏会锁定设备的本地时间。之后取景、重拍或延后截图，都保留这个已经记录的出生时刻，不改成截图时间。已出生却没有时间记录的旧存档保持未记录状态，不补填当前时间或虚构时刻；重新开始可记录新一局的剧情出生时刻。

## 内容与临床边界

这是母婴情况允许、团队持续照护的一条虚构分娩路径，不覆盖所有产程、剖宫产、助产和急救路径。剧情时间被大幅压缩，不代表真实产程。不会让玩家选择镇痛、指挥用力、实施接生、剪脐带、判断胎心或处理出血。临床操作由医护负责；改变方案不被解释为爸爸失败。

宝宝出生后，母亲的第三产程和评估仍在继续。首次接触与喂养由本人意愿、母婴情况和医护安排决定，不设必须立即接触、立即喂养成功的任务。示意毯小游戏不是婴儿体位或安全评估训练。任何现实担忧应告知工作人员。

本机记录使用 `dad-birth-journey-v1`，自动保存当前阶段、互动位置及已记录的剧情出生时刻；`dad-birth-complete` 用于成长地图的完成标记。纪念照片单独使用 `dad-birth-photo-v1`，可能受浏览器本地存储容量限制而无法续存；下载 PNG 可单独保留图片。所有记录留在当前浏览器，不上传。游戏不使用真实姓名或身份编号，腕带配对编号 `A-0618` 为虚构；纪念图中的时间来自设备本地时钟，指本局游戏的剧情出生时刻。旧篇和驾驶篇的存档保持独立。
