# 爸爸练习生：围产成长地图

已实现 10 个可独立游玩的中文章节，覆盖围产阶段主要家庭生活场景。所有章节开放，不要求按顺序解锁，也不要求重复刷关。这里的覆盖是家庭支持主题的覆盖，不是所有家庭、分娩方式或医疗并发症的穷举。

## 避免疲劳的设计

- 每章只使用一种主要玩法，不把所有内容套进“走过去—取物—交付”的循环。
- 保留已有两章；新章节不复制取水、递靠枕、换护等动作。
- 陪产和夜班中已有简短的联络、家属协调等桥段。新章节扩展的是路线、排程、资料或边界系统，不重复这些桥段的搬运动作。概念会自然出现，完整任务不复制。
- 新增八章不设倒计时、不扣生命值、不做连续登录和重复奖励。操作错误可调整，不重开整章。
- 新增章节在有意义的操作后自动存档，可以离开后继续；已有两章只保存最佳完成数。
- 完成即获得地图标记；可自由选章。无需为了通关按顺序完成所有章节。
- 提示、按钮和反馈独立排列在场景外，不用浮层挡住物体。暂停与玩法对话框由玩家主动打开。

## 内容边界与没有模拟的部分

每个家庭的生产方式、照护资源和文化背景不同。剖宫产或其他分娩方式后的个体化恢复、用药、喂养困难等在游戏中以“确认个人出院安排、联系专业团队”处理，没有模拟医疗操作。陪产规则与探视以医院要求及产妇意愿为准。

早产、NICU、妊娠丧失、严重并发症、复苏/急救手法等需要专门内容与专业审阅，当前没有实现为游戏；返岗、经济压力和不同家庭结构也没有独立关卡。不要将成长地图理解为这些情境的完整培训。

所有时间表、行李尺寸、交通图、支持容量和个案记录均为虚构。轮班关卡只排成人事务，不规定新生儿喂养或睡眠。安抚关不把停止哭泣作为成功指标。警示信号关必须先启动模拟求助，后整理信息，且不会拨打真实电话。没有诊断、剂量、医疗操作建议或照护能力评分。
