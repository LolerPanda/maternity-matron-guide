# 月嫂 / 育儿嫂面试评分表

一份可打印的月嫂 / 育儿嫂面试评分表，帮助待产家庭在面试时更有条理地考察候选人的专业知识和沟通性格。

## 内容

- [`月嫂面试评分表.pdf`](./月嫂面试评分表.pdf) — 可直接打印的 PDF 版本
- [`scorecard.html`](./scorecard.html) — 网页版源文件

## 涵盖的考察点

1. 黄疸判断与护理
2. 喂养判断（母乳 / 奶粉）
3. 呛奶与急救
4. 皮疹辨别（湿疹 / 热疹 / 激素疹）
5. 产妇护理与服务边界（涨奶、通乳职责划分）
6. 环境与操作细节（洗澡、脐带护理、温湿度、早教）
7. 恶露与产后身体观察
8. 乳头护理与开奶
9. 转奶与异常大便判断
10. 体重增长监测
11. 产后修复与工作边界
12. 沟通与性格现场观察清单

前 11 项每个知识点都附有「优秀 / 合格 / 不合格」三档参考答案（满分 33 分），方便面试时现场对照打分；第 12 项为现场观察打勾清单，不计入总分。
