3分・优秀
能说出"多吃多排、晒太阳"，并给出具体预警信号——比如黄疸范围一天内从脸部扩散到膝盖以下、宝宝精神差吃奶差手脚心发黄，就要及时就医测经皮胆红素。
2分・合格

0-1分・不合格
把黄疸和"上火"混为一谈；或坚持"母乳导致黄疸必须马上停奶"（这是过时说法，正规护理不会一概而论）。

"你怎么判断宝宝是不是吃饱了？我们家如果混合喂养，奶粉量大概怎么估？"
0
1
2
3
3分・优秀
综合看体重增长、大小便次数、吃奶后是否安稳，能说出"每个宝宝不同、给的是参考范围"，同时明确出生体重下降不超过出生体重的10%属正常。
2分・合格
能说出按月龄的大致奶量范围和常见信号（哭闹、找奶、尿布次数），但数字记不准，愿意如实说"不确定，到时候看情况"。
0-1分・不合格
报出的奶粉配比和奶量前后自相矛盾（比如说错勺数还坚持没错）；或被问到具体范围就情绪化、说"每个宝宝不一样"来搪塞所有问题。

皮疹辨别

满分 3
现场提问
"湿疹、热疹、激素疹你怎么区分？分别怎么护理？"
0
1
2
3
3分・优秀
激素疹＝母体激素影响，保持清洁干爽会自行消退；湿疹＝多与过敏/干燥有关，需要保湿护理；热疹＝闷热出汗导致，靠控温控湿预防。三者诱因、外观、处理方式都答得清楚。
2分・合格
大致能分开描述，但对处理方式说得笼统，比如统一说"保湿就好"或"擦点药就行"。
0-1分・不合格
把不同类型混为一谈（比如把疱疹说成"上火"），或者一遇到皮疹类问题就直接建议用药，不提护理方式。

满分 3
现场提问
"生理性胀奶你怎么处理？如果堵奶、乳腺炎了，是你来通还是要另外叫催乳师？费用怎么算？"
0
1
2
3
3分・优秀
生理性胀奶：多让宝宝吸、热敷/冷敷（土豆、包心菜等外敷）缓解，1-3天自行消退。主动说明自己的服务边界——只做日常观察和简单按摩放松，不做穴位精准手法，真正堵奶/乳腺炎建议请专业催乳师，且提前说清是否额外收费。
2分・合格
知道生理性胀奶的基本处理方法，但对"通乳算不算她的工作范围"含糊其辞，需要你追问才说清楚。
0-1分・不合格
一口答应"什么都能通"却说不出具体手法（可能是夸大承诺）；或者完全回避这个问题、态度不耐烦。
记录候选人原话（尤其是收费边界）

环境与操作细节

满分 3
现场提问
"脐带没脱落之前怎么给宝宝洗澡？房间温湿度你会控制在多少？平时早教都做些什么？"
0
1
2
3
3分・优秀
脐带未脱落优先擦身或上下身分开洗，下水需用防水脐贴；室温24-26℃、湿度50%-60%；水温37-38℃；早教能按月龄说出具体项目（黑白卡20-30cm、追视、抚触、俯卧抬头、排气操）并说明会随月龄调整。
2分・合格
大方向对，但数值记不准确（比如说不出具体温湿度范围），早教项目笼统说"就是多陪他玩"。
0-1分・不合格
说不出温湿度和水温的合理范围；早教环节完全答不上来，或者说"这个不重要，孩子这么小不用弄"。

沟通与性格观察

现场打勾，不计入知识总分
回答被追问细节时依然耐心，不敷衍
能诚实说"这个不确定/我不做"，而不是硬答
抱娃、模拟操作时动作轻柔、看着孩子
主动问你家里的具体情况和需求
混着问同一知识点时前后回答一致（非背模板）
语气平和，没有反驳、翻白眼、不耐烦
⚠ 出现以下任一情况：被多问几次就情绪激动 / 回答需要"旁边有人提示" / 眼神躲闪不看孩子 / 简历经历前后对不上——建议直接淘汰，不必纠结知识分数。
提醒：面试表现和上户后表现可能是两个人。熟人推荐的"好用"仅供参考——每家需求不同，且不排除有推荐返佣的情况。真正靠谱的判断，只能来自你自己当场提的这些问题和她当下的状态，而不是别人嘴里的口碑。
