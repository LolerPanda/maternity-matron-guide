# 今天的来访，由你亲自迎送

[进入游戏](../visitors.html) · [成长地图](../series.html)

方向键 / WASD 移动，E / 空格与身旁人物、物件互动。点击地面或“走向”按钮只负责绕家具走过去，到场还要亲自互动。对话用上下或左右键选择、E 确认，也可直接点按钮。手机有方向按钮。Esc 收起对话或暂停，切到其他页面自动暂停。

先问妈妈今天想怎样见面。对讲核对送餐身份，到家门接餐袋，再把餐袋带到餐台，携物会减速。与外婆说明客厅见面的范围，拉好卧室帘，亲自开门迎接。

带外婆时保持距离：走远了，她会原地等你，回去接上即可。访客不能进入卧室。到客厅座位旁按 E 安顿她，妈妈随后在客厅参与见面。临时朋友可能在带路途中到场，可以先回应，也可以先安顿外婆。

朋友未预约的探望可以换成门口留礼或稍后确认通话。外婆想合影时，再问妈妈：只留作家庭纪念、不转发，或这次不拍，两种安排都能继续。

妈妈表达疲惫并回到卧室后，原计划可以改变。向外婆说明今天先到这里，近距离带她到家门，再按 E 告别。关门、回来听妈妈当前的需要，最后在联络手机安排下一次支持。后续来访先问本人，或先协调送餐，都是可以协商的安排。

这些人物、时间和安排均为虚构。不评分父母，不按拒绝人数或速度评判表现，没有健康倒计时，不拨打真实电话。真实家庭以本人当下意愿为准。
